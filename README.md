Sistema de Reservas de Hotel
Projeto desenvolvido em Python.
Funcionalidades:
- Cadastro e listagem de clientes
- Listagem de quartos
- Realização de reservas
- Verificação de disponibilidade por datas
- Cálculo do valor da hospedagem

Conceitos utilizados:
- Programação orientada a objetos
- Classes e métodos
- Herança e polimorfismo
- Estruturas condicionais e de repetição
- Tratamento de exceções

Como executar:
- Ter o Python instalado.
- Baixar o arquivo main.py.
- Abrir o terminal na pasta do arquivo.
- Executar python main.py.

!! Os dados ficam armazenados temporariamente na memória durante a execução do programa. !!
